# 📌 Logging with Multiple Loggers in Python

*(Different modules ke liye alag-alag logging control)*

---

## 1️⃣ Core Idea (Plain Hinglish)

* Real applications **single file nahi hoti**
* Multiple modules / files / components hote hain
* Har module ka:

  * alag responsibility
  * alag logging need hoti hai

👉 **Multiple loggers** ka matlab:

* Har module ke liye **separate logger**
* Har logger ka **alag log level**
* Logs zyada **readable, structured, debuggable**

---

## 2️⃣ Problem with Single (Root) Logger

Pehle hum kya kar rahe the:

* Sab kuch **root logger** se log ho raha tha
* Output me:

  ```
  root - DEBUG - message
  ```

❌ Issue:

* Pata nahi chalta kaunsa message **kis module** se aaya
* Large project me debugging messy ho jati hai

👉 Solution = **Named Loggers (Multiple Loggers)**

---

## 3️⃣ Logger Create Karna (Most Important Concept)

Python logging me:

```python
logging.getLogger("logger_name")
```

* Ye ek **named logger** create karta hai
* `logger_name` usually:

  * module ka naam
  * feature ka naam

---

## 4️⃣ Example: Module-wise Loggers

### 🔹 Step 1: Import logging

```python
import logging
```

---

### 🔹 Step 2: Logger for Module 1

```python
logger1 = logging.getLogger("module1")
logger1.setLevel(logging.DEBUG)
```

👉 Module 1:

* Development / logic heavy
* Isliye **DEBUG level**

---

### 🔹 Step 3: Logger for Module 2

```python
logger2 = logging.getLogger("module2")
logger2.setLevel(logging.WARNING)
```

👉 Module 2:

* Stable / production type
* Sirf **WARNING, ERROR, CRITICAL**

---

## 5️⃣ basicConfig (Common Configuration)

```python
logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s"
)
```

📌 Yahan:

* `%(name)s` → **logger ka naam** (module1 / module2)
* Isse output clear hota hai

---

## 6️⃣ Logging with Different Loggers

### Module 1 logs:

```python
logger1.debug("This is a debug message for module1")
```

### Module 2 logs:

```python
logger2.warning("This is a warning message for module2")
logger2.error("This is an error message for module2")
```

👉 Result:

* Module 1 → DEBUG logs allow
* Module 2 → DEBUG ignore, WARNING & ERROR allow

---

## 7️⃣ Output kaise dikhega (Conceptually)

```
2026-01-12 10:30:12 - module1 - DEBUG - This is a debug message for module1
2026-01-12 10:30:15 - module2 - WARNING - This is a warning message for module2
2026-01-12 10:30:18 - module2 - ERROR - This is an error message for module2
```

👉 Ab clearly dikh raha hai:

* kaunsa module
* kaunsa level
* kaunsa message

---

## 8️⃣ Why Multiple Loggers Matter (Real Projects)

* Large codebase (DS / Backend / ML pipelines)
* Different teams, different modules
* Selective logging:

  * Dev module → DEBUG
  * Stable module → WARNING / ERROR

👉 **Debugging 10x easier**

---

## 9️⃣ Common Mistakes & Confusions

❌ Sab jagah root logger use karna
❌ Logger name na dena
❌ Sab modules me DEBUG level rakhna
❌ Logger banaya par `setLevel()` nahi kiya

---

## 🔟 One-Page Revision Points

* `logging.getLogger("name")` → named logger
* Har module ke liye alag logger possible
* Har logger ka:

  * alag level
  * alag behavior
* `%(name)s` → logger ka naam show karta hai
* Professional apps me **multiple loggers mandatory**

---

## 1️⃣1️⃣ If You Forget Everything, Remember This 👇

> **Multiple loggers ka matlab hai:
> Har module ka apna logger, apna level, apni clarity.
> Large applications me root logger se aage badhna hi padta hai.**
