# 📌 Logging in Python

*(Application execution ko track, debug aur monitor karne ka system)*

---

## 1️⃣ Core Idea (Plain Hinglish)

* **Logging** ka matlab hai:
  👉 program ke andar jo bhi important cheezein ho rahi hain (info, warning, error, crash)
  👉 unko **record** karna
* End-to-end projects me **print() useless ho jata hai**
* Logging se hum:

  * Errors trace kar sakte hain
  * Debug easily kar sakte hain
  * Production issues samajh sakte hain

👉 **Serious application = Logging mandatory**

---

## 2️⃣ Why Logging is Important (Real Reason)

* Debugging ke time pata chalta hai:

  * error **kab** aaya
  * **kis level ka** tha
  * **kaunse function** me issue hua
* Production me:

  * User ko error dikhao ya nahi → separate
  * Developer ke liye **log file me full detail**

👉 **Logging = application ka black box recorder**

---

## 3️⃣ Python Logging Module (Basics)

* Python me **built-in `logging` module** hota hai
* Flexible framework provide karta hai:

  * log levels
  * formatting
  * file logging

```python
import logging
```

---

## 4️⃣ Logging Levels (MOST IMPORTANT)

| Level    | Use Case                                |
| -------- | --------------------------------------- |
| DEBUG    | Detailed info (development time)        |
| INFO     | Normal flow confirmation                |
| WARNING  | Something unexpected, app still running |
| ERROR    | Serious issue, function fail            |
| CRITICAL | App crash level problem                 |

### Meaning samajh lo:

* **DEBUG** → developer ke liye
* **INFO** → sab theek chal raha
* **WARNING** → future me problem ho sakta hai
* **ERROR** → kaam nahi hua
* **CRITICAL** → app band ho sakta hai

---

## 5️⃣ Basic Logging Configuration

```python
logging.basicConfig(level=logging.DEBUG)
```

* Ye batata hai:

  * minimum kaunsa level log hoga
* DEBUG diya → **sab levels print honge**

---

## 6️⃣ Logging Messages kaise likhte hain

```python
logging.debug("This is a debug message")
logging.info("This is an info message")
logging.warning("This is a warning message")
logging.error("This is an error message")
logging.critical("This is a critical message")
```

### Default output me kya hota hai:

* Date & time
* Log level
* Message

---

## 7️⃣ Custom Logging Format (Very Important)

Hum apna format define kar sakte hain:

```python
logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S"
)
```

### Format tokens ka matlab:

* `%(asctime)s` → time stamp
* `%(name)s` → logger name
* `%(levelname)s` → DEBUG / INFO / ERROR
* `%(message)s` → actual message

---

## 8️⃣ File Logging (Real Projects Me Ye Use Hota Hai)

### Log file me save karna:

```python
logging.basicConfig(
    filename="app.log",
    filemode="w",
    level=logging.DEBUG,
    format="%(asctime)s - %(levelname)s - %(message)s"
)
```

👉 Ab:

* Terminal me print nahi
* **Sab logs `app.log` file me save**

⚠️ `filemode="w"` → overwrite
⚠️ `filemode="a"` → append

---

## 9️⃣ VERY IMPORTANT RULE (Exam + Practical)

❗ **`basicConfig()` sirf ek baar kaam karta hai**

* Agar pehle configure ho chuka hai
* Dobara change karna ho →
  👉 **Kernel / interpreter restart required**

---

## 🔟 Logging ko Multiple Files me Use Karna (Professional Setup)

### logger.py

```python
import logging

logging.basicConfig(
    filename="logs/app.log",
    level=logging.DEBUG,
    format="%(asctime)s - %(levelname)s - %(message)s"
)
```

---

### test.py

```python
from logger import logging

def add(a, b):
    logging.debug("Addition operation is taking place")
    return a + b

logging.debug("Addition function is called")
add(10, 15)
```

👉 Result:

* Kuch print nahi hoga
* `app.log` file me **pure execution ka record**
