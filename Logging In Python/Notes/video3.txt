## 3️⃣ Step 1: Import & Basic Logging Configuration

```python
import logging
```

### Logging configuration (Advanced way):

```python
logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S",
    handlers=[
        logging.FileHandler("app1.log"),
        logging.StreamHandler()
    ]
)
```

### Iska matlab:

* `DEBUG` → sab logs allow
* `FileHandler` → logs file me save
* `StreamHandler` → console me show
* `%(name)s` → module / logger name

👉 **Professional setup**

## 5️⃣ Step 3: Arithmetic Functions + Logging

### ➕ Add Function

```python
def add(a, b):
    result = a + b
    logger.debug(f"Adding {a} + {b} = {result}")
    return result
```

---

### ➖ Subtract Function

```python
def subtract(a, b):
    result = a - b
    logger.debug(f"Subtracting {a} - {b} = {result}")
    return result
```

---

### ✖ Multiply Function

```python
def multiply(a, b):
    result = a * b
    logger.debug(f"Multiplying {a} * {b} = {result}")
    return result
```

---

### ➗ Divide Function (With Error Handling)

```python
def divide(a, b):
    try:
        result = a / b
        logger.debug(f"Dividing {a} / {b} = {result}")
        return result
    except ZeroDivisionError:
        logger.error("Division by zero error occurred")
```

👉 **Error log hoga, app crash nahi karega**
