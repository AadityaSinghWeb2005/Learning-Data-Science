

📌 CRUD Operations with SQLite & Python

(Python se local relational database ko manage karna)

1️⃣ Core Idea (Plain Hinglish)

        SQL ek language hai jo relational databases ko manage karti hai

        SQLite usi SQL ka lightweight, serverless version hai

        Python ke andar built-in support hota hai SQLite ka

        Hum Python code se:

        Database banate hain

        Table create karte hain

        Data Create, Read, Update, Delete (CRUD) karte hain

👉 SQLite basically ek file hoti hai (.db), jo local system me store hoti hai

2️⃣ SQL vs SQLite (Difference clear karo)
Feature	SQL (MySQL/Postgres type)	SQLite
Server required	✅ Yes	❌ No
Configuration	Heavy	Zero
Storage	Server based	Local .db file
Usage	Large apps	Embedded / small apps
Python support	External setup	By default installed

👉 SQLite = fast, simple, portable

3️⃣ Step-by-Step Flow (End-to-End)
🔹 Step 1: Import SQLite
import sqlite3


Python 3 me by default available hota hai

🔹 Step 2: Database Create / Connect
connection = sqlite3.connect("example.db")


Agar file exist nahi karti → automatically create ho jati hai

Ye hi reason hai ki SQLite embedded systems me popular hai

🔹 Step 3: Cursor Create
cursor = connection.cursor()


Cursor SQL commands ko execute karta hai

Tables aur rows ke upar iteration karta hai

🔹 Step 4: Table Create
CREATE TABLE IF NOT EXISTS employees (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    age INTEGER,
    department TEXT
)


Primary key compulsory hoti hai

IF NOT EXISTS error se bachata hai

Execute:

cursor.execute(query)
connection.commit()


⚠️ Commit mandatory hai (warna changes save nahi honge)

4️⃣ INSERT (Create Operation)
🔹 Single Record Insert
INSERT INTO employees (name, age, department)
VALUES ('Krish', 32, 'Data Scientist')


Execute + Commit:

cursor.execute(query)
connection.commit()

🔹 Multiple Inserts (Bulk Insert)
cursor.executemany("""
INSERT INTO sales (date, product, sales, region)
VALUES (?, ?, ?, ?)
""", sales_data)

connection.commit()


👉 executemany() = performance fast, loop ki zarurat nahi

5️⃣ READ (Select / Query Data)
SELECT * FROM employees


Python side:

cursor.execute("SELECT * FROM employees")
rows = cursor.fetchall()

for row in rows:
    print(row)


Output tuple format me aata hai

(id, name, age, department)

6️⃣ UPDATE Operation
UPDATE employees
SET age = 34
WHERE name = 'Krish'

cursor.execute(query)
connection.commit()


⚠️ Commit nahi kiya → update reflect nahi hoga

7️⃣ DELETE Operation
DELETE FROM employees
WHERE name = 'Bob'

cursor.execute(query)
connection.commit()

8️⃣ Connection Close (Very Important)
connection.close()


DB permanently close ho jata hai

Uske baad koi query run karoge → ❌ error

👉 Ye real-world analytics pipeline ka base hai

10️⃣ Why This Matters in Data Science

Local experiments ke liye best DB

Small to medium datasets

ETL pipelines

Feature engineering data store

Interview me SQL + Python combo strong banata hai

11️⃣ Common Confusions & Mistakes

❌ commit() bhool jana
❌ SQL syntax mistake (form instead of from)
❌ Connection close ke baad query run karna
❌ Primary key na banana

12️⃣ One-Page Revision Points

SQLite = serverless SQL database

.db ek normal file hoti hai

Flow:

connect → cursor → execute → commit → close


CRUD:

Create → INSERT

Read → SELECT

Update → UPDATE

Delete → DELETE

Bulk insert = executemany()

13️⃣ If You Forget Everything, Remember This 👇

SQLite ek lightweight database hai jo Python ke saath directly kaam karta hai.
Cursor SQL chalata hai, commit changes save karta hai, aur close ke baad DB lock ho jata hai.
CRUD = INSERT, SELECT, UPDATE, DELETE.
